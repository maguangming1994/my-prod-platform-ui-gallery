# 星链移动端与后台运营中心成品 UI 设计稿 V2

当前总览在原有移动端画板基础上，新增 15 套后台桌面画板、30 个主界面/详情态。后台不另设预览入口，统一在 `index.html#admin` 查看和对比。

后台画板以线上 `frontend/apps/admin-web/src/App.vue` 为唯一结构基线：保留登录与账号安全、经营总览，以及线上已有的 14 个导航模块、真实字段和原有操作；设计补充项均在画板中以“本轮补全”单独标识，不与已实现能力混淆。

当前总览加载 `admin-live-boards.js`。远端原有的 `admin-boards.js` 继续保留为上一版目标画板，方便历史对照，不在本轮覆盖。

## 后台账号角色与数据范围

- 超级管理员：全国数据，负责跨域配置、授权与生产发布。
- 用户/交易运营：账号、实名、多身份、订单、履约和售后事实管理。
- 平台招商/商品运营：OPC 准入、类目资质、保证金、四类商品与履约规则。
- 区域运营：仅查看授权区域，审核代理、席位、首批进货和销售归属。
- 财务/财税：收益、追缴、提现双审、支付、税务资料与渠道对账。
- 客服/治理：会话、工单、内容申诉、任务活动、O2O 争议与证据裁定。
- 系统/风控审计：RBAC、支付配置、区域高校、品牌协议、风险与操作日志。

代理业务边界：代理无商品发布权限，仅可采购星卡、审核下级代理，以及提交并审核本区域销售。

## 跨端闭环

移动端发起 → 后台按账号角色和数据范围受理 → 审核/支付/履约执行 → 移动端展示结果 → 审计留痕与异常复核。

本目录只放高保真成品 UI 画板，不再混入页面目录、原型说明器或设计管理界面。

## 视觉基准

- 深海蓝 `#0B1F33`
- 主操作青绿 `#0F766E`
- 白色表面与冷灰 `#F5F7FA` 页面背景
- 星卡、价格和待办使用琥珀色
- 红色只用于真实错误与危险操作
- 清晰中文、真实图片、12–16px 圆角、细边框和克制阴影

这 117 个关键界面用于锁定完整设计语言、角色差异与真实实施边界，其余长尾场景继续按同一组件、业务模板和状态规则扩展。

画板是目标设计，不代表所有业务都已上线。尤其 24–38 号后台画板只表达目标信息架构和交互方向；其中“线上原有”仅表示结构或字段来源于线上页面，不表示该画板已经完整实施。金额、数量、时效、退款与月结文案均为演示占位，不得作为已配置业务规则或当前实现证据。在线总览中的“流程与实现状态”及本目录的实施矩阵，才是当前设计与代码覆盖关系的评审入口。

## 已锁定业务修正

- 代理库存只有付费星卡，不包含耳机、面霜、箱包等普通实物商品。
- 03、04 号画板中代理采购普通实物及“库存商品”的内容属于旧稿错误，不作为开发依据。
- 代理端统一采用第 11、16、17 号画板表达的星卡首批进货、库存批次、补货、利润与激活流程。
- 普通实物 SKU 与库存归 OPC 管理；销售可以推广商品，但代理不因此持有普通商品库存。

完整人工确认结果见 [多角色 UI 业务决策](../../../product/多角色UI业务决策-2026-08-10.md)。后续修图和代码实现必须同步遵守其中的课程购买、现金钱包、角色导航、公开编号、会员期限和代理席位规则。
